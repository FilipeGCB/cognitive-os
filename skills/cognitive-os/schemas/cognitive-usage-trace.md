# Cognitive Usage Trace V1.5

`cognitive-usage-trace.schema.json` is the executable contract for the local
Flight Recorder. It is intentionally a typed operational record, not a
conversation log.

The local record may retain bounded counters needed for diagnostics. A shared
event is produced by `telemetry.flight_recorder.build_shared_payload()` and is
a stricter projection: it removes local counters, candidate names, precise
timestamps, provenance detail, prompts, responses, documents, paths, URLs and
all free text.

Required invariants:

- `schema_version` is `1` and every enum is allowlisted;
- `run_id` is host-shaped (`CRR-...`) and generated by the runtime, never by
  model prose;
- `event_id` is a random, non-identifying `EVT-...` idempotency key generated by
  the runtime; it is not a persistent installation identifier;
- capability discovery, authentication, run consent, invocation and result
  are separate states;
- counts shared outside the host are buckets (`0`, `1-3`, `4-10`, `11+`);
- custom skills, MCPs, connectors and private systems are represented only as
  `custom_capability` in shared payloads;
- unknown fields are rejected at every object boundary;
- no prompt, assistant response, chain-of-thought, document, file content,
  credential, cookie, token, private URL, detailed research query, PII or
  arbitrary text is accepted by the shared projection.

The shared sender is optional and starts `OFF`. A host without persistence,
preview or outbound-send capability reports the corresponding telemetry mode as
`UNAVAILABLE`; the Cognitive OS run remains usable.
