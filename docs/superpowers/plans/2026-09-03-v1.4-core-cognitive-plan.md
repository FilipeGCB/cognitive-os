# Cognitive OS v1.4 Core Cognitive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the self-contained public Cognitive OS skill with the proven V1.3 decision core plus V1.4 Adaptive Discovery Interview, sensemaking, Outside View, Value of Information, robustness, and Decision Quality closure behavior.

**Architecture:** The runtime product lives entirely under `skills/cognitive-os/` and is Markdown/schema driven. Cognitive routing remains adaptive and host-neutral; vendor-specific capabilities are referenced only through abstract capability contracts. Historical V1.3 evidence remains outside this public repo and is not rewritten.

**Tech Stack:** Agent Skills Markdown format, JSON examples where structured records help, Python 3.11+ standard-library validation tests.

**Spec:** `docs/superpowers/specs/2026-09-03-cognitive-os-v1.4-public-product-design.md`

## Global Constraints

- Runtime use must not require consulting GitHub.
- `skills/cognitive-os/` must remain self-contained.
- Do not expose or persist chain-of-thought.
- Do not invent evidence, reference classes, base rates, probabilities, thresholds, capability availability or execution.
- Simple questions remain simple; no ritual interview or framework checklist.
- Cognitive OS may recommend/handoff but does not self-authorize consequential execution.
- Public text must not depend on Filipe-specific, private-vault, Vivo or Host-A artifacts.
