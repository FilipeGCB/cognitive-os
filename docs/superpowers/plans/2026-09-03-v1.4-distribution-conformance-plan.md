# Cognitive OS v1.4 Distribution and Conformance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Package Cognitive OS for public discovery and installation while proving that the distributable skill is self-contained, private-data-free, host-neutral and behaviorally conformant.

**Architecture:** The repo exposes one canonical runtime skill plus thin host/distribution adapters. CI validates structure, public-safety rules, tests and eval manifests. Marketplace adapters do not fork the cognitive core.

**Tech Stack:** Agent Skills directory convention, Markdown, JSON/YAML manifests where required, Python 3.11+ standard-library CI tests, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-cognitive-os-v1.4-public-product-design.md`

## Global Constraints

- No imported private-vault Git history or private-vault dependency.
- No private/corporate/personal references required only by the originating environment.
- Releases are immutable distribution points.
- `skills/cognitive-os/` alone must contain the runtime cognitive package.
- Host-specific packaging is a thin adapter only.
- No release/tag until all release gates pass.

- [ ] **Step 3: Implement validator**
