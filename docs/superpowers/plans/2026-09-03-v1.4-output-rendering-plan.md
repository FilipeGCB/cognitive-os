# Cognitive OS v1.4 Output and Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Cognitive OS end in a clear, editorially strong Decision Brief while preserving Decision Pack as structured truth and Cognitive Run Record as separate audit evidence.

**Architecture:** Output behavior is defined by a skill reference and schema semantics. Markdown is the portable canonical human projection; optional HTML is generated from a deterministic lightweight renderer outside the runtime skill. Visual rules are explicit and testable without creating a dashboard framework.

**Tech Stack:** Markdown, HTML/CSS, Python 3.11+ standard library.

**Spec:** `docs/superpowers/specs/2026-09-03-cognitive-os-v1.4-public-product-design.md`

## Global Constraints

- Decision Pack remains the canonical structured decision record.
- Decision Brief is a human/editorial projection, not a parallel source of truth.
- Cognitive Run Record remains separate audit evidence.
- Normal output must not expose internal framework ritual unless useful or explicitly requested.
- Conclusion comes early; idea evolution is shown when an initial proposal exists.
- No pseudo-precision confidence percentages.
- Markdown remains portable; HTML is derived and optional.

- [ ] **Step 3: Implement minimal Markdown subset renderer**

Use only standard library. Support headings, paragraphs, emphasis, unordered lists, fenced code and simple pipe tables used by our examples. Escape raw HTML by default. Template must use semantic `<main><article>` structure.

CSS requirements:
- body 18px default with responsive reduction;
- line-height 1.6;
- content max-width 780px;
- title around 2rem;
- h2 around 1.35rem;
- section spacing around 3rem;
- system font stack only;
- restrained borders;
- light/dark via `prefers-color-scheme`;
- links/focus visible;
- no status communicated only by color.
