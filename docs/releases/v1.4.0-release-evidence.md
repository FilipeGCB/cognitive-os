## Capability / companion status

No third-party companion is promoted as `supported` or installed by default in v1.4.0.

- `notebooklm-py` / NotebookLM MCP: candidate, Gauntlet status `test`; pinned at v0.8.2; specific consent and account authentication required. CI may prove package/entrypoint installability without proving user-account authentication or NotebookLM service behavior.
- OpenNotebookLM: preferred open-source candidate for the next direct grounded-corpus integration test; not default/supported.
- Open Notebook: candidate; not default/supported.
- SurfSense: `continue-research`; broader research platform and mixed licensing in part of the repository; not default/supported.
- AnythingLLM: candidate; not default/supported.
- Firecrawl: candidate for Structured Crawl; no bundled/default install.

Therefore the release does not claim runtime validation of a companion that has not been exercised with its required account/data context.

## Behavioral conformance

V1.4 behavioral conformance is separate from deterministic CI.

The public suite contains 29 cases:

- 19 core behavior cases (`evals/v1.4-core-cases.json`);
- 10 output/editorial cases (`evals/v1.4-output-cases.json`).

The credential-free reference workflow uses a pinned local Ollama runtime and `qwen3:4b`, with a separate grader invocation per case. Model thinking output is disabled because the suite grades observable answers rather than private reasoning traces.

Stable promotion requires:

- at least 27/29 cases passing;
- zero failures among the declared 9 critical cases (`V14-C06`, `V14-C10`, `V14-C12`, `V14-C16`, `V14-C18`, `V14-C19`, `V14-O03`, `V14-O07`, `V14-O10`);
- preserved JSON evidence artifact;
- explicit recording of model/grader limitations.

In local execution environments, local Ollama execution on CPU requires ~200 seconds per LLM turn (~400 seconds per evaluated case), making local 29-case execution (~3+ hours) unviable within sandbox timeouts. Full 29-case behavioral conformance is executed in GitHub Actions via `.github/workflows/conformance.yml`.
