# Cognitive OS V1.5 — Optional Remote API Conformance Runbook

**Status:** optional QA utility; not a ChatGPT plugin requirement and not a mandatory V1.5 release blocker  
**Workflow:** `.github/workflows/conformance.yml` / `v1.5-conformance`  
**Local LLMs:** prohibited

## Why this exists

This workflow is an optional automated behavioral QA harness for maintainers who deliberately want to spend remote API quota on a 58-case SUT + independent-grader run.

It is **not required to create, test, submit, approve or install the ChatGPT/Codex plugin**. ChatGPT plugins run inside the ChatGPT/Codex product surfaces and do not require the plugin author to buy an OpenAI inference API key merely because a plugin exists.

The V1.5 plugin path is validated through package/contract checks, deployed MCP protocol evidence, and host/plugin testing on the actual ChatGPT/Codex surface when available. External directory approval remains a platform review state.

## Optional setup

If a maintainer voluntarily chooses to run this API harness, configure an explicit remote SUT and an independent remote grader plus their corresponding GitHub Actions secrets. Do not paste credentials into workflow inputs, commits, PR comments, logs, issues or documentation.

The workflow intentionally has **no provider/model defaults**. Missing configuration fails closed as `UNAVAILABLE`; it never falls back to Ollama or another local provider.

## Optional run

GitHub repository -> Actions -> `v1.5-conformance` -> `Run workflow`.

Choose `dev` for targeted QA or `final` for the full 58-case optional suite. Supply explicit remote provider/model/base URLs only when the release owner intentionally elects to use paid/quotad APIs.

A passing optional run may be attached as additional evidence, but absence of such a paid run does not block `v1.5.0` and must not be confused with ChatGPT Plugin Directory requirements.

## Mandatory release evidence instead

Before stable V1.5, the project still requires truthful evidence for the product claims it actually makes:

1. deterministic/core/privacy/distribution CI green;
2. Find Skills + Find MCP installation/discovery contracts green;
3. deployed telemetry collector and consent/improvement-queue evidence green;
4. Claude package validation green for the claim being made;
5. OpenAI plugin package + deployed MCP protocol evidence green;
6. actual ChatGPT host smoke if the release claims `HOST_E2E_VALIDATED`; otherwise use the narrower `PLUGIN_SUBMISSION_READY / HOST_SMOKE_PENDING` claim;
7. stable `1.5.0` metadata/evidence sync, final CI, merge, post-merge validation and tag/release.

No paid inference API key is inherently required by those plugin-release steps.
