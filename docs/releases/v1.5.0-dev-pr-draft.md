arquitetura canônica, corrigindo os findings da V1.4 antes das novas
capacidades, sem merge em `main` e sem publicar release.

`41a14aa839c87609597cb0cdd3ff81cd06b61135`; a tag `v1.4.0` apontava para

## Principais mudanças

- contratos JSON Schema e validators determinísticos para run, capability,
  forensic, usage trace, distribution e release evidence;
- capability state separado em availability, auth, run consent, invocation e
  result;
- Capability Discovery 2.0 estendendo o registry/adapter existente;
- Find Skills/Find MCP representados como discovery assets, com identidade não
  comprovada mantida como `BLOCKED`, sem substituto inventado;
- Web→Corpus routing, checkpoints de budget, migração configurável,
  truth-domain reconciliation e fechamento após rate limit;
- grounded strategy, governança de self-improvement, mutation/side-effect
  ledgers e provider closure;
- Flight Recorder local, modos de telemetria, forensic bundle opt-in e cliente
  público privacy-preserving construído por allowlist;
- contratos honestos por host e quatro manifests de distribution com smoke no
  artefato projetado/instalado;
- runner V3 com seleção dev (determinístico + afetado + crítico), seleção por
  caso/tag/família, `critical-only`, fases SUT/grading separadas, checkpoints
  atômicos, cache por caso/fingerprint e concorrência limitada;
- 58 evals V1.5 nas famílias CD, RS, GS, SI, TL, PR, HP, DS, MC e RC, além
  das regressões V1.4.

## Segurança e privacidade

O shared payload não aceita prompt, resposta, raciocínio, documentos, conteúdo
de arquivo, nome/path privado, URLs privadas, nomes de cliente/projeto, PII,
credenciais, tokens, cookies, queries detalhadas ou texto livre. O default é
`OFF`; sem capacidade real de host/endpoint, compartilhamento fica
`UNAVAILABLE`. Gate T passou com schema, allowlist, sanitizer, preview,
consentimento, dry-run, rejeição de campos desconhecidos, limites e testes
adversariais. O collector privado foi criado somente após prova programática
de `visibility=private`; nenhum secret ou endpoint privado foi adicionado ao
repositório público.

## Bloqueadores e limitações conhecidos

Este PR é Draft e não autoriza release estável. Permanecem:

1. evidência Hermes com Gate 9 bloqueado por capabilities não observadas;
2. runtime Work não disponível neste ambiente;
3. identidades exatas dos discovery assets originalmente pretendidos não
   comprovadas, sem substituto inventado;
4. compartilhamento de telemetria sem endpoint aprovado e capability de host;
5. collector privado sem deployment/operations evidence.
